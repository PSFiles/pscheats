    PlayStation Guide

    How to Install and Use Cheats on Your Console

    PS4 · GoldHEN Cheat Manager Setup

    GoldHEN reads cheat codes in JSON format matching your game's Title ID (e.g. CUSA00123_01.00.json).

    1. Direct File Transfer: Download the .json file using the Download File button on the game page.
    2. Destination Path: Using FTP or PS4-Xplorer, copy the file to: 
      /user/data/GoldHEN/cheats/json/
    3. In-Game Activation: Launch the game. Hold the Share or Options button (configured in GoldHEN settings) or press L3 + R3 to bring up the GoldHEN Cheat Menu overlay.
    4. Navigate with D-Pad and toggle cheats on or off using Cross. Return to your game with Circle.

    PS4 · Configuração com GoldHEN Cheat Manager

    O GoldHEN lê os códigos de trapaça em formato JSON correspondentes ao Title ID do jogo (ex.: CUSA00123_01.00.json).

    1. Transferência Direta: Baixe o arquivo .json pelo botão Download File na página do jogo.
    2. Caminho de Destino no Console: Via cliente FTP ou gerenciador de arquivos (PS4-Xplorer), copie o arquivo para: 
      /user/data/GoldHEN/cheats/json/
    3. Ativação Durante o Jogo: Inicie o jogo. Segure o botão Share ou Options (conforme configurado nas opções do GoldHEN) ou pressione L3 + R3 para abrir o menu suspenso do GoldHEN.
    4. Navegue com o D-Pad e ative/desative os cheats com o botão Cross. Pressione Circle para voltar ao jogo.

    PS5 · HEN & GoldHEN Cheats Setup

    PS5 jailbroken consoles running HEN utilize GoldHEN-compatible cheat JSON structures.

    1. Download & Placement: Download the .json cheat file for your game Title ID.
    2. Internal Storage Path: Transfer via FTP to the console internal directory: 
      /user/data/GoldHEN/cheats/json/  or  /data/GoldHEN/cheats/json/
    3. Opening the Overlay: While playing your title, invoke the cheat overlay with your configured shortcut (default Create or Options hold).
    4. Use D-Pad Up and Down to browse, toggle with Cross, and confirm.

    PS5 · Configuração de Cheats com HEN

    Consoles PlayStation 5 desbloqueados com HEN utilizam o formato compatível JSON do GoldHEN.

    1. Download e Envio: Baixe o arquivo de cheats .json correspondente ao Title ID do jogo.
    2. Pasta no Armazenamento Interno: Envie via FTP para o caminho: 
      /user/data/GoldHEN/cheats/json/  ou  /data/GoldHEN/cheats/json/
    3. Abertura do Menu em Jogo: Com o jogo em execução, acione o menu de trapaças pelo atalho configurado (segurar Create ou Options).
    4. Utilize o D-Pad para escolher os códigos, confirme com Cross e retorne com Circle.

    PS3 · ArtemisPS3 Homebrew Setup

    ArtemisPS3 uses .ncl database files containing cheat lists and assembly patches.

    1. Exporting the File: Click Download File to get the formatted .ncl file (named TITLE_SERIAL.ncl).
    2. Copying to PS3 Storage: Place the .ncl file onto a FAT32 USB drive in /ARTEMIS/ or directly into internal HDD: 
      /dev_hdd0/game/ARTEMIS00/USRDIR/user/
    3. Selecting Cheats: Launch the ArtemisPS3 homebrew application on your PS3. Navigate to Cheats, locate your game title, select desired codes with Cross, and press Square to attach cheats to memory.
    4. Starting Game & Activation: Artemis returns to the XMB. Launch your game disc or digital package. When ready in-game, press PS Button + Start to activate the loaded codes.

    PS3 · Configuração com ArtemisPS3

    O ArtemisPS3 utiliza arquivos de banco de dados .ncl contendo códigos de trapaça e patches de memória.

    1. Exportação do Arquivo: Clique em Download File para obter o arquivo .ncl formatado (nomeado TITULO_SERIAL.ncl).
    2. Cópia para o PS3: Coloque o arquivo .ncl em um pendrive FAT32 na pasta /ARTEMIS/ ou diretamente no HDD interno: 
      /dev_hdd0/game/ARTEMIS00/USRDIR/user/
    3. Seleção de Trapaças: Abra o aplicativo ArtemisPS3 no seu PS3. Vá em Cheats, encontre o jogo, marque os códigos desejados com Cross e pressione Square para fixar os códigos na memória.
    4. Início do Jogo e Ativação: O Artemis retorna para a XMB. Inicie o jogo normalmente. Durante o jogo, pressione PS Button + Start para ativar o mecanismo de trapaças.

    PS Vita · VitaCheat Plugin Setup

    VitaCheat reads .psv database files stored in the VitaCheat directory.

    1. Exporting .psv: Click Download File to obtain the [TITLEID].psv database file.
    2. Destination Path: Copy the file to your memory card using VitaShell (via USB or FTP): 
      ux0:vitacheat/db/[TITLEID].psv
      (e.g., ux0:vitacheat/db/PCSE00001.psv)
    3. In-Game Activation: Launch your Vita game. Press the VitaCheat activation combo: L1 + D-Pad Left (or L1 + D-Pad Right depending on your vitacheat config).
    4. Use D-Pad Up and Down to scroll, toggle cheats with Cross, and press Circle to return to gameplay.

    PS Vita · Configuração com Plugin VitaCheat

    O VitaCheat lê arquivos de trapaça em formato .psv armazenados no cartão de memória.

    1. Exportando o .psv: Clique em Download File para obter o arquivo [TITLEID].psv.
    2. Pasta no PS Vita: Transfira o arquivo para o cartão usando o VitaShell (por USB ou FTP): 
      ux0:vitacheat/db/[TITLEID].psv
      (ex.: ux0:vitacheat/db/PCSE00001.psv)
    3. Acionamento Durante a Partida: Inicie o jogo no PS Vita. Pressione a combinação de ativação: L1 + D-Pad Esquerda (ou L1 + D-Pad Direita).
    4. Navegue com o D-Pad, ative/desative os códigos com Cross e saia do menu pressionando Circle.
